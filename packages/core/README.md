# @agent-feedback/core

Framework-independent browser and server primitives for Agent Feedback.

This package contains the annotation overlay, element selection, payload
generation, HTTP client, local broker, JSONL persistence, and structured logs.
Most applications should install `@agent-feedback/cli` and use the Vite or
Next.js integration instead of configuring the core package directly.

See the [Agent Feedback repository](https://github.com/montanaflynn/agent-feedback) for full documentation.
