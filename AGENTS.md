# Repository instructions

Always test and update relevant documentation before committing after finishing a task.

Use Conventional Commits for commit messages and pull request titles. Prefer descriptive branch prefixes such as `feat/`, `fix/`, `docs/`, `chore/`, or `refactor/`.

Do not use or reference agent branding in branch names, commit messages, pull request titles, pull request bodies, or user-facing summaries unless explicitly requested.
